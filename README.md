# 🍔 Lanchonete — Cardápio Digital

Um projeto de lanchonete desenvolvido para apresentar produtos de forma organizada e proporcionar uma experiência prática e intuitiva aos usuários.

O projeto faz parte dos meus estudos em desenvolvimento web, com foco na criação de interfaces interativas e no aprimoramento das minhas habilidades com HTML5, CSS3 e JavaScript.

## 🚀 Funcionalidades

- 🍔 Exibição dos produtos disponíveis no cardápio.
- 🥤 Apresentação de informações e preços dos produtos.
- 🛒 Interação com os itens do cardápio.
- 💰 Cálculo de valores dos produtos selecionados, caso implementado.
- 🖥️ Interface visual intuitiva e organizada.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estruturação dos elementos e organização do conteúdo.
- **CSS3:** estilização da interface, cores, layouts e elementos visuais.
- **JavaScript:** implementação da lógica, interatividade e manipulação dos elementos da página.

## 📚 Objetivos de Aprendizado

Durante o desenvolvimento deste projeto, busquei praticar conceitos importantes, como:

- Estruturação de páginas com HTML5.
- Estilização e organização de interfaces com CSS3.
- Manipulação do DOM com JavaScript.
- Eventos e interações com o usuário.
- Organização e manutenção do código.
- Integração entre HTML, CSS e JavaScript.
